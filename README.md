## Selected projects

### e2D

A Python and Cython toolkit for real-time 2D simulations, optimized vector mathematics and ModernGL rendering.

It started as a practical wrapper around Pygame and evolved into an independent graphics and simulation library built around ModernGL, GLFW, NumPy and compiled vector operations.

### Darius

A self-hosted personal automation system built as a set of modular services for memory, model routing, tool execution, web interfaces, notifications and workload delegation between a VPS and local hardware.

The private production codebase doubles as a practical environment for distributed systems, observability, LLM orchestration, cost-aware routing and infrastructure engineering. A sanitized public architecture repository documents the system design and selected engineering decisions.

### 2D Electric Field Line Simulator

A real-time interactive electrostatics simulation that traces field lines around multiple point charges using numerical integration and JIT-compiled physics.

The project combines vectorized computation, Numba acceleration, interactive charge manipulation and real-time visualization built on top of e2D.

## Teaching

I designed and taught an after-school Python course for high-school students, taking approximately fifteen participants from the fundamentals of programming to a complete final project.

The course covered variables, strings, control flow, functions and program structure through progressive exercises, culminating in a fiscal-code generator assembled from smaller reusable components.

I have also taught introductory programming with Scratch to younger students.
